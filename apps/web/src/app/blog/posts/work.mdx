## Menambah Proyek Baru

Semua proyek disimpan sebagai file `.mdx` di direktori:
`src/app/work/projects/`

## Format Metadata Proyek

Proyek memerlukan beberapa informasi tambahan di frontmatter dibandingkan postingan blog biasa:

<CodeBlock codes={[{ code: `---
title: "Judul Proyek"
publishedAt: "2026-03-01"
summary: "Deskripsi singkat hasil karya."
images: ["/images/projects/cvr-1.jpg", "/images/projects/cvr-2.jpg"]
team: [{ name: "Nama", role: "Jabatan", avatar: "/img.jpg" }]
link: "https://proyek-langsung.com"
---`, language: 'markdown' }]} />

## Visibilitas

Halaman proyek akan secara otomatis muncul di rute `/work` dan juga di bagian "Projects" pada halaman beranda jika rute tersebut diaktifkan di konfigurasi.
