## Struktur Blog

Magic Portfolio menggunakan Next.js App Router dan MDX untuk mengelola konten blog. Semua postingan disimpan sebagai file `.mdx` di direktori berikut:

`src/app/blog/posts/`

## Format Postingan

Setiap postingan harus memiliki blok frontmatter di bagian paling atas:

<CodeBlock compact marginBottom="16" codes={[
  {
    code: `---
title: "Judul Postingan Anda"
summary: "Ringkasan singkat tentang isi postingan."
publishedAt: "2026-03-06"
tag: "Kategori"
image: "/images/blog/thumbnail.jpg" // Opsional
---`,
    language: "markdown"
  }
]} />

## Menggunakan Komponen

Anda dapat menggunakan komponen UI sistem langsung di dalam file MDX. Contoh penggunaan `CodeBlock`:

<CodeBlock compact marginBottom="16" codes={[
  {
    code: "<CodeBlock codes={[{ code: 'npm run dev', language: 'bash' }]} />",
    language: "markdown"
  }
]} />
