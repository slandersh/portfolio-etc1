## Menambah Halaman Baru

Untuk menambah halaman statis baru:
1. Buat folder baru di `src/app/` (misalnya `src/app/contact/`).
2. Tambahkan file `page.tsx` di dalam folder tersebut.
3. Daftarkan rute baru Anda di `once-ui.config.ts` agar muncul di navigasi otomatis.
