## Avatar

Ganti file `public/images/avatar.jpg` dengan gambar avatar Anda sendiri. Gambar ini digunakan di halaman `/about` dan juga pada gambar `open-graph` yang di-generate secara dinamis.

## Favicon

Ganti file `src/app/favicon.ico` dengan favicon Anda sendiri.

## Konten Utama

Sebagian besar data dipusatkan di `src/resources/content.tsx`. Namun, untuk konten besar seperti **Store** dan **Stream**, datanya kini dipisahkan ke file masing-masing untuk kemudahan pengelolaan:
- `src/resources/store.ts` (Produk, Jasa, Donasi)
- `src/resources/stream.ts` (Link stream, Berita stream)

### Detail Pribadi

Detail pribadi Anda digunakan di seluruh aplikasi untuk merender heading, label, dan gambar yang dipersonalisasi.

### Link Sosial

Link sosial dirender di halaman `/about` dan di footer berdasarkan array yang dikonfigurasi di objek `social`.
