## Tentang

Magic Portfolio adalah template portofolio responsif, ramah SEO, berbasis MDX yang dibangun dengan Once UI dan Next.js.

## Lisensi

Magic Portfolio dilisensikan di bawah [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). Anda hanya dapat menggunakannya untuk tujuan pribadi, dan Anda harus mencantumkan atribusi karya asli. Atribusi ditambahkan di footer secara default, tetapi Anda dapat menempatkannya di bagian lain yang terlihat di situs Anda.

Berlangganan [Once UI Pro plan](https://once-ui.com/pricing) untuk memperluas lisensi ke [Dopler CC](https://once-ui.com/products/magic-portfolio).
