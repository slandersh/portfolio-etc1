## Metadata Global

Atur judul dan deskripsi default aplikasi Anda di `src/resources/content.tsx` pada objek `person` dan `home`. Ini akan digunakan sebagai dasar untuk semua halaman.

## Metadata Per Halaman

Next.js secara otomatis mengambil `title` dan `summary` dari frontmatter file MDX Anda untuk dijadikan tag metadata SEO halaman tersebut. Pastikan setiap postingan memiliki deskripsi yang relevan dan mengandung kata kunci penting.

## Open Graph Images

Magic Portfolio secara otomatis menghasilkan gambar Open Graph (gambar berbagi sosial) yang dinamis menyertakan nama, avatar, dan judul postingan Anda.
